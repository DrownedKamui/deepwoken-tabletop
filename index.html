Подключение к партии

Открой приложение у ведущего и игроков. Введите адрес сервера, имя и код комнаты. Игроки видят общую карту и состояние боя; ведущий управляет полем и врагами.

Запусти сервер из комплекта. PIN ведущего задан переменной GM_PIN (по умолчанию 2468).

Участники комнаты

Пока никто не подключён.

Как играть с телефона

  1. Для игры только с телефона размести этот проект на Node.js-хостинге через браузер телефона (см. README_RU.md).
  2. Открой выданную HTTPS-ссылку на каждом телефоне; для установки нажми меню браузера → «Добавить на главный экран».
  3. Все вводят одинаковый код комнаты; ведущий выбирает роль «Ведущий».
  4. Состояние синхронизируется между участниками. Данные партии сохраняются на сервере.

Общая тактическая карта

Игроки видят карту в реальном времени. Изменение поля и размещение NPC доступны ведущему. Клетка условно равна 5 футам.

Схематические оригинальные карты — не точные игровые карты. Собственные изображения можно импортировать локально; для синхронизации картинки отправляются серверу как часть состояния, поэтому лучше использовать небольшие файлы.

Листы персонажей

Игрок может создать и редактировать свой лист. Ведущий видит все листы. Изменения синхронизируются в комнате.
