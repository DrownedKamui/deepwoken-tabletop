
# Deepwoken Tabletop

Мобильная многопользовательская настольная игра по мотивам Deepwoken.

## Возможности

- Общие комнаты для игроков и ведущего
- Тактическая клеточная карта
- Листы персонажей
- Броски кубиков
- Инициатива и бой
- Заметки ведущего и противники
- Мобильный интерфейс и PWA

## Структура проекта

- `server.js` — сервер Express и Socket.IO
- `package.json` — зависимости и команда запуска
- `public/index.html` — интерфейс игры
- `public/manifest.webmanifest` — настройки PWA
- `public/sw.js` — Service Worker
- `public/icon.svg` — иконка приложения

## Запуск

Требуется Node.js.

Установить зависимости:

    npm install

Запустить сервер:

    npm start

Открыть в браузере:

    http://localhost:3000

## Подключение игроков

Укажи адрес сервера в интерфейсе игры. Все участники должны использовать один и тот же адрес и код комнаты.

Для роли ведущего нужен PIN.

По умолчанию PIN — `2468`. Перед публикацией рекомендуется изменить его, задав переменную окружения `GM_PIN`.

## Развёртывание на Render

Тип сервиса: Web Service.

Build Command:

    npm install

Start Command:

    npm start

## Ограничения текущей версии

- Состояние комнат хранится в оперативной памяти сервера.
- Данные могут потеряться при перезапуске сервера.
- Постоянное хранение данных в базе пока не настроено.
