# Deepwoken Tabletop v3 — версия с приоритетом на телефон

## Что добавлено
- **Eastern Luminant** — оригинальная схематическая карта с островами, ориентировочными маршрутами и ключевыми локациями. Это не точная игровая карта и не в масштабе.
- Установка как PWA: после публикации открой HTTPS-ссылку в Chrome на Android → меню `⋮` → **Добавить на главный экран** / **Установить приложение**.
- Кэширование оболочки для более быстрого повторного открытия. Для общей онлайн-партии интернет и сервер всё равно нужны.
- Оставлены общая комната, листы персонажей, кубы, инициатива, бестиарий, заметки и тактическое поле.

## Важно: что реально возможно без компьютера
Сам файл приложения можно открыть и использовать на телефоне, но **мультиплеер для разных телефонов не может работать постоянно без сервера**. Серверный проект лежит в `server.js`. Ниже — один из способов развернуть его с телефона через браузер; названия кнопок на хостингах могут меняться.

## Публикация только с Android-телефона (через GitHub + Render)
1. Открой GitHub в браузере телефона и войди или создай аккаунт.
2. Создай новый репозиторий, например `deepwoken-tabletop`. Загрузи файлы проекта, включая `server.js`, `package.json`, `public/` и `README_RU.md`. Не загружай `node_modules` или `rooms.json`.
3. Открой Render в браузере телефона и подключи этот GitHub-репозиторий как **Web Service**.
4. Настройки сервиса: **Build Command** `npm install`; **Start Command** `npm start`; runtime — Node.
5. Добавь переменную окружения `GM_PIN` со своим непредсказуемым PIN (не используй `2468`). Если у хостинга есть постоянный диск, подключи его для сохранения `rooms.json`; без постоянного диска данные могут пропасть после перезапуска/переразмещения.
6. После публикации открой HTTPS-адрес сервиса. В приложении введи этот же адрес, имя и код комнаты. Ведущий выбирает роль «Ведущий» и вводит PIN; остальные — «Игрок».
7. На каждом телефоне открой этот адрес в Chrome → меню `⋮` → **Добавить на главный экран**.

Если бесплатный тариф выбранного хостинга не поддерживает постоянное хранение файлов или ограничивает WebSocket/сон сервиса, данные могут не сохраняться либо первое подключение будет медленным. Для постоянной кампании потребуется хостинг с WebSocket и постоянным диском или база данных.

## Игра в одной Wi-Fi сети
Нужен телефон/устройство, на котором можно запустить Node.js, например Android с Termux. Это сложнее, чем облачный хостинг, и не обязательно для игроков. Установи Node.js в Termux, распакуй проект, выполни `npm install`, затем `GM_PIN='твой-пин' npm start`. Остальные телефоны должны открывать локальный IP телефона-сервера и порт `3000`. Если всё у тебя только на одном телефоне, этот способ неудобен — лучше облачный хостинг.

## Безопасность и ограничения
- Это прототип, а не законченная защищённая онлайн-платформа: PIN ведущего — базовая защита, аккаунтов нет.
- Не используй пароль от важных сервисов как PIN ведущего.
- Данные комнат хранятся в `rooms.json`; для долговременной игры нужен постоянный диск/БД.
- Не добавляй в общие заметки тайны ведущего — сейчас заметки общие.
- Схема Eastern Luminant создана специально для этого приложения и условна. Список локаций сверялся с фан-вики Deepwoken; расположение и маршруты на схеме не претендуют на точность.

## Локальный запуск (если когда-нибудь появится компьютер)
`npm install` → `GM_PIN="твой-пин" npm start` → открыть `http://localhost:3000`.
